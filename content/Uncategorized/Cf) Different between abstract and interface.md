# 1. 상수 유무
> 추상 클래스는 인스턴스 변수를 가질 수 있으며, 자식 클래스에 변수나 메서드의 시그니처를 강제할 수 있다. 하지만 인스턴스 변수는 객체마다 개별적으로 존재하므로 메모리를 공유하지 않는다.  
인터페이스에 선언된 필드는 암묵적으로 `public static final`이 적용되며, 모든 필드는 정적 상수(static constant)로 취급된다.

### Cf) 변수가 final인 이유
- 1. 다중 상속 시 변수 중복 방지
- 2. 정적 상수의 목적
#### Ex) 의미를 지니는 상수표현
```java
int MALE = 0
int FEMALE = 1;
```
