# 1. 동기화와 블로킹
## 1.1. 정의

- 동기(Synchronous) / 비동기(Asynchronous), 
- 블로킹(Blocking) / 논블로킹(Non-blocking)에 대한 개념 정리

## 1.2. 목적

- 각 개념 간의 차이점을 명확히 이해하고, 개발 상황에서 적절하게 적용하기 위함

***
# 2. 특징

## 2.1. 동기화/ 비동기

| 구분     | 설명 |
|----------|------|
| **동기** | 작업의 완료 여부를 확인하고 **순차적으로 처리**함 |
| **비동기** | 작업의 완료 여부를 따지지 않고 **병렬적으로 처리** 가능 |

- 작업의 완료 여부의 차원에서 구분됨


## 2.2. 블록킹/논블록킹

| 구분       | 설명                              |
| -------- | ------------------------------- |
| **블로킹**  | 작업 중 제어권을 넘기고 **기다림**           |
| **논블로킹** | 작업 중 제어권을 유지하고 **다른 작업을 처리** 가능 |
