# 1. 이진트리
- **정의**: [[트리 (Tree)]] 중 각 노드가 최대 2개의 자식노드를 가지는 트리
- **특징**
	- 왼쪽 자식노드와 오른쪽 자식노드는 구별
## 1.1. 이진트리의 종류

| 종류                                            | 정의                                              | 특징                          |
| --------------------------------------------- | ----------------------------------------------- | --------------------------- |
| 정 이진트리 (Strict Binary Tree, Full Binary Tree) | 모든 노드가 자식이 0개이거나 2개인 이진트리                       | 자식이 1개인 노드가 없음              |
| 포화 이진트리 (Perfect Binary Tree)                 | 모든 레벨이 꽉 찬 이진트리                                 | 모든 리프가 같은 깊이에 존재            |
| 완전 이진트리 (Complete Binary Tree)                | 마지막 레벨을 제외한 모든 레벨이 꽉 차 있고, 마지막 레벨은 왼쪽부터 차 있는 트리 | 배열로 구현하기 적합, 힙에서 사용         |
| 편향 이진트리 (Skewed Binary Tree)                  | 모든 노드가 한쪽 자식만 가지는 이진트리                          | 왼쪽 편향 / 오른쪽 편향, 탐색 성능 저하 가능 |
| 균형 이진트리 (Balanced Binary Tree)                | 왼쪽 서브트리와 오른쪽 서브트리의 높이 차가 크지 않은 트리               | 탐색, 삽입, 삭제 성능이 비교적 안정적      |
| 이진 탐색 트리 (BST, Binary Search Tree)            | 왼쪽 자식은 부모보다 작고, 오른쪽 자식은 부모보다 큰 값을 가지는 이진트리      | 중위 순회 시 오름차순 정렬             |
| 힙 (Heap)                                      | 부모와 자식 간 대소 관계를 만족하는 완전 이진트리                    | 최대 힙 / 최소 힙으로 나뉨            |
| AVL 트리                                        | 높이 균형을 유지하는 이진 탐색 트리                            | 균형이 엄격하여 탐색 성능이 좋음          |
| 레드-블랙 트리 (Red-Black Tree)                     | 색상 규칙으로 균형을 유지하는 이진 탐색 트리                       | AVL보다 삽입/삭제 시 회전 부담이 적음     |
| 포화 이진트리 (Full Binary Tree)                    | 모든 레벨이 꽉 찬 이진트리                                 | 모든 리프가 같은 깊이에 존재            |
|                                               |                                                 |                             |
### 1.1.1. 정 이진트리(Full Binary Tree)
- 모든 노드가 2개의 자식을 가지거나 자식이 없는 경우
	- 이명 **엄격한 이진트리(Strict Binary Tree)**

### 1.1.2. 포화 이진트리(Perfect Binary Tree)
- 모든 노드가 2개의 자식 노드로 구성 + 모든 leaf 노드가 같은 레벨
- 높이가 $h$ 일 경우, 모든 노드의 개수 = $2^{h+1} - 1$

### 1.1.3. 완전 이진트리(Complete binary tree)
- 두가지 필요 충분 조건
	1. 마지막 레벨(level)을 제외하고 모든 노드가 채워져 있여야함
	2. 노드는 왼쪽부터 채운다.
	- Thus) 왼쪽 노드는 없지만 오른쪽 노드는 존재한다면 완전 이진트리 X
