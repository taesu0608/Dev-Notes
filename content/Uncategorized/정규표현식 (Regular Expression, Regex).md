# 1. 정규 표현식(Regular Expression, Regex)
- **정의**: 문자열에서 특정한 규칙을 가진 패턴을 정의하고 이를 검색, 검사, 추출, 치환하기 위해 사용하는 표현 방식

# 1.1. 문자 매칭(Character Matching)
### 1.1.1. 일반 문자
|표현|의미|예|
|---|---|---|
|`a`|문자 a|`a`|
|`abc`|문자열 abc|`abc`|
### 1.1.2. 메타 문자
| 표현  | 의미            |
| --- | ------------- |
| `.` | 모든 문자 (개행 제외) |
| `\` | escape        |
# 1.2. 문자 클래스(Character Class)
### 1.2.1. 문자, 이미 정한 문자

| 표현식        | 의미            | 예          |
| ---------- | ------------- | ---------- |
| `[abc]`    | a 또는 b 또는 c   | `[abc]`    |
| `[a-z]`    | 소문자 알파벳       | `[a-z]`    |
| `[A-Z]`    | 대문자 알파벳       | `[A-Z]`    |
| `[0-9]`    | 숫자            | `[0-9]`    |
| `[a-zA-Z]` | 모든 알파벳        | `[a-zA-Z]` |
| `[^abc]`   | a,b,c 제외      | `[^abc]`   |
| `[^0-9]`   | 숫자 제외         | `[^0-9]`   |
| `.`        | 모든 문자 (개행 제외) | `a.c`      |
| `\d`       | 숫자            | `\d+`      |
| `\D`       | 숫자 제외         | `\D+`      |
| `\w`       | 문자 + 숫자 + `_` | `\w+`      |
| `\W`       | `\w` 제외       | `\W+`      |
| `\s`       | 공백 문자         | `\s+`      |
| `\S`       | 공백 제외         | `\S+`      |
## 1.3. 수량자(Quantifiers)
|표현식|의미|예|
|---|---|---|
|`*`|0개 이상 반복|`a*` → `""`, `a`, `aa`, `aaa`|
|`+`|1개 이상 반복|`a+` → `a`, `aa`, `aaa`|
|`?`|0 또는 1개|`a?` → `""`, `a`|
|`{n}`|정확히 n개|`\d{3}` → `123`|
|`{n,}`|n개 이상|`\d{2,}` → `12`, `123`|
|`{n,m}`|n개 이상 m개 이하|`\d{2,4}` → `12`, `123`, `1234`|
|`*?`|0개 이상 최소 반복 (lazy)|`<.*?>`|
|`+?`|1개 이상 최소 반복 (lazy)|`a+?`|
|`??`|0 또는 1 최소 반복 (lazy)|`a??`|
|`{n,m}?`|범위 최소 반복 (lazy)|`\d{2,4}?`|
