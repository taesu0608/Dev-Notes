# 1. 데이터 전송 흐름 주체

>통신 프로그래밍에서 사용하는 Server와 Client 개념은 웹 개발에서의 개념과 다르다.  
 웹 개발에서는 서비스를 제공하는 측을 Server, 서비스를 이용하는 측을 Client로 구분한다.  
 반면 통신 프로그래밍에서는 연결의 안정성 관점에서 구분하며, 안정적인 통신 상태를 유지하는 쪽을 Server, 연결을 시도하는 쪽을 Client로 본다.
 Server는 연결 요청을 수동적으로 대기하며 안정적인 통신 상태를 유지하는 역할을 한다.  
 Client는 능동적으로 Server에 연결을 요청하고 통신을 시작한다.  
 이러한 특성 때문에 통신 프로그래밍에서는 Server를 Passive Opener, Client를 Active Opener라고 부른다.
