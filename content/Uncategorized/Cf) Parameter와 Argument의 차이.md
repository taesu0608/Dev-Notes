| 구분       | Parameter                                | Argument                         |
| -------- | ---------------------------------------- | -------------------------------- |
| 정의 위치    | 함수 또는 메서드 **선언부**에서 사용됨                  | 함수 또는 메서드 **호출부**에서 전달됨          |
| 역할       | 전달받을 값을 **받아줄 변수**                       | 함수에 실제로 **전달되는 값**               |
| 예시       | `void greet(String name)` → `name`이 파라미터 | `greet("hajung")` → `"하정"`가 아규먼트 |
| 의미       | 변수명(placeholder) 역할                      | 실질적인 데이터(value) 역할               |
| 개수 일치 여부 | 보통 파라미터 개수와 아규먼트 개수가 일치해야 함              | 가변 인자, 기본값 등을 통해 일부 예외 있음        |
