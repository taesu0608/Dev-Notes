# 1. 선택 정렬 (Selection Sort)
- 제자리 정렬(in-place sorting) 알고리즘의 하나
	- 입력 배열(정렬되지 않은 값들) 이외에 다른 추가 메모리를 요구하지 않는 정렬 방법

## 1.1. 선택 정렬
1. 주어진 배열 중에서 최솟값 탐색
2. 해당 값을 맨 앞에 위치한 값과 교체
3. 맨 처음 위치를 제외한 나머지 리스트를 같은 방법으로 교체
4. 하나의 원소만 남을때까지 1~3 과정을 반복

### 1.1.1. 최솟값 탐색
- 각 회전마다 범위내 최솟값 원소를 찾아야 함
- 범위 내 모든 원소를 탐색하여 최솟값 배열의 index를 저장

## 1.2. 특징
- 자료 이동 횟수가 미리 결정
- 안정성 불만족
	- **안정성(stability)**: 외부 기준이나 규칙이 적용되더라도 불필요한 순서 변화가 발생하지 않는 특성
	- i.e.) 선택 정렬의 경우 같은 값이여도 순서 변화가 발생함
		- 동일 원소 간 직접적인 교환이 없더라도, 다른 원소와의 비연속적인 교환 과정에서 상대적 순서가 변경될 수 있음
		- **이터레이터(Iterator)**: 반복 과정에서의 **단일 단계의 상태**
## 1.3. 시간 복잡도
### 1.3.1. 비교 횟수
- 외부 반복: (n-1)번
	- 최솟값 마지막 남은 요소는 최댓값이기에 시행하지 않음
- 내부 반복: 정렬할 요소 수 - 1
	- 정렬할 요소 수 = 전체 요소 수 - 정렬된 요소 수
### 1.3.2. 교환 횟수
- 상수 시간
	- 외부 루프의 실행 횟수와 동일, 1회전당 1번 교환
- 3(n-1)번
	- 1회 교환을 위해 3번의 이동 소요(SWAP 함수의 작업)
- `T(n) = (n-1) + (n-2) + … + 2 + 1 = n(n-1)/2 = O(n^2)`
#### 내부 반복에서 `-1`이 있는 이유
>기준 요소가 고정된 상태에서,  
반복 횟수는 그 기준과 비교되어야 할  
대상 요소의 개수에 의해 결정된다.
