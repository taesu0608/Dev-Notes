# 1. 좌표 압축(Coordinate Compression)
- **정의**: 값의 상대적인 크기 순서는 유지하면서, 작은 연속 정수(generally around 0)로 치환하는 알고리즘

## 1.1. 좌표 압축 과정
1. 입력된 순서에 따라 `index` 와 값 저장
2. 값의 크기를 기준으로 오름차순 정렬
3. 정렬된 값을 앞에서부터 확인하며 압축 값을 부여
    - 이전 값과 같으면 같은 압축값 부여
    - 이전 값보다 크면 압축값 + 1 부여
4. 마지막으로 원래 `index` 기준으로 다시 정렬하여 입력 순서에 맞게 복원

### 1.1.1. 좌표 압축 과정 예시
1. 값 입력
$$5, 10, 2, 7, 13, -3$$
2. 입력된 순서에 따라 `index`와 값 저장
$$(0, 5), (1, 10), (2, 2), (3, 7), (4, 13), (5, -3)$$
3. 값의 크기를 기준으로 오름차순 정렬
$$(5, -3), (2, 2), (0, 5), (3, 7), (1, 10), (4, 13)$$
4. 압축값(generally around 0) 부여
$$(5, 0), (2, 1), (0, 2), (3, 3), (1, 4), (4, 5)$$
5. `index`기준 재정렬
$$(0, 2), (1, 4), (2, 1), (3, 3), (4, 5), (5, 0)$$
6. 출력
$$2, 4, 1, 3, 5, 0$$
