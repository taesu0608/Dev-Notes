### Cf) 시간 복잡도에 따른 대표 알고리즘
| 시간 복잡도       | 예시 알고리즘 / 연산                                                             |
| ------------ | ------------------------------------------------------------------------ |
| O(1)         | Stack의 push, pop 연산                                                      |
| O(log n)     | 이진 탐색(Binary Search), 이진 트리 탐색                                           |
| O(n)         | 단일 for 루프                                                                |
| O(n × log n) | 퀵 정렬(Quick Sort), 병합 정렬(Merge Sort), 힙 정렬(Heap Sort)                     |
| O(n²)        | 중첩 for 루프, 삽입 정렬(Insert Sort), 버블 정렬(Bubble Sort), 선택 정렬(Selection Sort) |
| O(2ⁿ)        | 피보나치 수열(재귀 방식)                                                           |
