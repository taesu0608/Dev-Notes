# 2. EOF in Java

## 2.1. 동작 원리

- Java의 read() 메서드가 -1 또는 null을 반환한다.
###### Q) Java의 read() 메서드가 파일 종료 감지 원리 
###### A) OS(운영체제)와의 상호작용 순서

- Java의 `InputStream.read()`는 내부적으로 OS의 네이티브 API를 호출한다.
    
- 운영체제는 파일 디스크립터에 현재 읽기 위치인 **파일 커서(포인터)** 를 저장한다.
    
- 데이터를 읽을 때마다 커서는 **앞으로 이동**하며 다음 읽기 위치로 진행된다.
    
- 파일의 끝에 도달하면, OS는 Java에 **0 바이트 또는 -1을 반환**해 EOF를 알린다.
