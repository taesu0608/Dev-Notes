# 1. 기본자료형 (Primitive Types)
## 1.1. 정수 자료형
![[Pasted image 20260320185059.png]]
### 1.1.1. 정수 오버플로우/ 언더플로우
- **오버플로우**: 해당 타입이 표현할 수 있는 `최대 표현 범위`보다 큰 수를 저장할 때 발생하는 현상
- **언더플로우**: 해당 타입이 표현할 수 있는 `최소 표현 범위`보다 작은 수를 저장할 때 발생하는 현상

```java
byte max = 127; //byte의 범위 -128부터 127
byte min = -128;

System.out.println(max + 1000); // ERROR
System.out.println(min - 1000); // ERROR
```

### 1.1.2. underscore 표기법
- 쉼표(comma)를 활용한 큰 수 표기가 아닌 **underscore**를 사용
```java
int cost = 1000_000_000; // 1000000000
```

### 1.1.3. 2진수/ 8진수/ 16진수
```java
// 0(숫자 '0')으로 시작하면 8진수
int octal = 023; 

// 0x(숫자 '0' + 알파벳 'x')로 시작하면 16진수    
int hex = 0xC; 

// 0b(숫자 '0' + 알파벳 'b')로 시작하면 2진수    
int binary 0b101
```

### 1.2.1. 실수 자료형 표기
```java
float pi = 3.14F; //F,f 리터럴 타입 접미사 추가
```

### 1.2.2. 실수의 표현 오차
- 컴퓨터는 소수를 이진법으로 표현할때 **고정 소수점 방식**이 아닌 **부동 소수점 방식** 을 이용한다.
1. **고정소수점 방식**: 12.345
2. **부동소수점 방식**: $1.abc \times 2^b$
	- 정밀한(precision) 소수 처리 방식이지만 정확(accuracy)하지는 않다.

#### 정확한 소수점 연산 방식
1. 정수화
	- $0.14 \times 100$ 를 통해 14로 값 사용 이후 $100 mod$
2. `BigDecimal` 클래스 사용
## 1.3. 문자 자료형
### 1.3.1. char
1. 2 byte 정수
	- char는 일부 UniCode를 표현
		- ASCII ⊂ Unicode (Unicode = ASCII + (한글, 일본어, 이모지, 기타 문자, etc))
2. char끼리 합은 int형으로 변환된다
```java
public static void main(String[] args) {  
	char a = 'A'; // 65  
	char b = 'B'; // 66  
	  
	int result = a + b;  
	  
	System.out.println(result); // 131  
}
```
