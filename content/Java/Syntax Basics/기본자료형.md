## 1.1. 기본자료형 범위
| 자료형       | 비트 수   | 최소값                        | 최대값                         | 비고                 |
| --------- | ------ | -------------------------- | --------------------------- | ------------------ |
| `byte`    | 8      | -128                       | 127                         | 정수                 |
| `short`   | 16     | -32,768                    | 32,767                      | 정수                 |
| `int`     | 32     | -2,147,483,648             | 2,147,483,647               | 정수 (기본)            |
| `long`    | 64     | -9,223,372,036,854,775,808 | 9,223,372,036,854,775,807   | 정수                 |
| `float`   | 32     | ±1.4 × 10⁻⁴⁵               | ±3.4028235 × 10³⁸           | 실수 (부동소수점)         |
| `double`  | 64     | ±4.9 × 10⁻³²⁴              | ±1.7976931348623157 × 10³⁰⁸ | 실수 (기본)            |
| `char`    | 16     | 0 (`\u0000`)               | 65,535 (`\uFFFF`)           | **unsigned**, 유니코드 |
| `boolean` | JVM 의존 | `false`                    | `true`                      | 논리값                |
1. char+char는 int형으로 계산이 된다.
## 1.2. 정수 오버플로우/ 언더플로우

- **오버플로우**: 해당 타입이 표현할 수 있는 `최대 표현 범위`보다 큰 수를 저장할 때 발생하는 현상
- **언더플로우**: 해당 타입이 표현할 수 있는 `최소 표현 범위`보다 작은 수를 저장할 때 발생하는 현상

```java
byte max = 127;
byte min = -128;

System.out.println(max + 1000);
System.out.println(min - 1000);
```
