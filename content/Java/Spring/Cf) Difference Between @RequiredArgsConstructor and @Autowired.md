
# 1. 정의

|항목|@RequiredArgsConstructor|@Autowired|
|---|---|---|
|적용 대상|클래스(롬복이 생성자를 만들어줌)|생성자, 세터, 필드|
|동작 시점|**컴파일 타임**(코드 생성)|**런타임**(컨테이너가 주입)|
|주입 트리거|생성자 하나일 때 Spring이 자동 주입|애노테이션이 붙은 멤버에 명시적 주입|
|대상 필드|`final`/`@NonNull`만 생성자 파라미터로 포함|제한 없음(필드/세터/생성자 어디든)|

# 2. 비교
- @RequiredArgsConstructor
	- 보일러 플레이트 제거(생성자 자동)
	- 불변성 확보(`final` 필드)
		- `Autowired`생략 가능
	- 순환 참조 미리 확인
- @Autowired
	- 주입 위치를 명시적으로 제어 (불변성 약화)
		- 생성자, 세터, 필드
	- 주입 조건,시점,대상을 정하는 어노테이션과 활용
