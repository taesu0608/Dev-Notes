# 1. 타입 추론
## 1.1. 일반 타입 추론(Local Variable Type inference)

-  `var`, 제네릭, new 표현 등에서 컴파일러가 타입 결정
#### Ex) var
```java
var x = new user("kim");
```

## 1.2. 함수형 인터페이스 기반 타입 추론(Contextual Type Interface)
- 람다식/메서드 참조의 타입을 함수형 인터페이스의 "함수 디스크립터"로 추론
#### Ex) 함수형 인터페이스
```java
Function<Integer, String> f = x -> x + "1";
```
