
일급 객체(First Class Citizon)
- 일급 객체의 목적
	- 함수 자체를 객체처럼 다룰 수 있는 기준을 제시함
- 일급 객체의 조건
	1. 변수에 값을 할당할 수 있어야함
	2. 함수의 파라미터로 넘겨줄 수 있어야함
	3. 함수의 반환값이 될 수 있어야함

- 기존의 자바의 메서드는 일급객체의 조건에 만족하지않음
- Java 8 이후 함수를 일급객체처럼 다룰 수 있게 함수형 인터페이스를 제공

@Functionallnterface 어노테이션
- Java8에 추가된 어노테이션

**함수형 인터페이스(Function Interface)는 추상 메서드가 딱 하나만 존재하는 인터페이스**

람다식은 이러한 함수형 인터페이스를 기반으로만 작성

## 2.1. 함수 디스크럽터(Function Descriptor)

- 함수형 인터페이스의 단일 추상 메서드(SAM: Single Abstract Method)의 시그니처 **(매개변수 타입과 반환 타입)**

##### Cf) 정확히는 시그니처의 3가지 요소인 메서드명, 매개변수 타입, 매개변수의 수에서 메서드 명을 제외한 것을 말한다.

#### Ex) SAM 시그니처
``` java
@FunctionalInterface
pubilc interface IntBinaryOperator {
	int applyAsInt(int left, int right);
}
```
- 함수 디스크럽터: (int, int) -> int
