## 1.1. 정수형 자료형

- `byte` (1 byte)
    - 범위: -128 ~ 127
- `short` (2 byte)
    - 범위: 약 ±32,000
- `int` (4 byte)
    - 범위: 약 ±21억
    - 기본 정수형
- `long` (8 byte)
    - 범위: 약 ±9 * 10^18

```java
int a = 10;
long b = 10000000000L; // 반드시 L 붙이기
```
- long 변수 대입 시, 대입하는 숫자의 값이 int 자료형 최댓값(2147483647)

## 2. 자료형 선택 기준

### 기본 원칙

- 정수 계산 → `int`
    
- 큰 정수 → `long`
    
- 매우 큰 수 → `BigInteger`
    
- 나머지 문제 → `mod 연산`
    

---

## 3. BigInteger

### 사용 이유

- long 범위를 초과하는 경우
    

```java
import java.math.BigInteger;

BigInteger a = new BigInteger("12345678901234567890");
BigInteger b = BigInteger.valueOf(10);
```

### 연산

```java
a.add(b);
a.subtract(b);
a.multiply(b);
a.divide(b);
a.mod(b);
```

⚠️ 연산자 사용 불가

## 4. 기본 연산

### 산술 연산

```java
+  -  *  /  %
```

```java
int a = 7 / 3; // 2
int b = 7 % 3; // 1
```

---

### 증감 연산

```java
i++;
++i;
```

차이:

- `i++` → 후위 증가
    
- `++i` → 전위 증가
    

---

### 비교 연산

### 논리 연산

## 6. 오버플로우

### 예시

```java
int x = Integer.MAX_VALUE;
x++; // overflow 발생
```

### 해결 방법

- long 사용
    
- BigInteger 사용
    
- mod 연산 사용
    

---

## 7. 모듈러 연산 (중요)

### 핵심 성질

```java
(a + b) % m = (a % m + b % m) % m
(a * b) % m = (a % m * b % m) % m
```

### 사용 예

```java
dp[i] = (dp[i-1] + dp[i-2]) % 10007;
```

---

## 8. 나눗셈 주의

```java
(a / b) % m ❌
```

→ 모듈러에서는 나눗셈이 어려움  
→ 필요 시 "모듈러 역원" 사용

---

## 9. 알고리즘에서의 실전 기준

### 선택 기준

1. overflow 발생 가능?
    
2. mod 필요한 문제인가?
    
3. 시간 복잡도 괜찮은가?
    

### 추천 패턴

- DP → int + mod
    
- 조합 → DP or mod inverse
    
- 큰 수 정확 계산 → BigInteger
    

---

## 10. 핵심 요약

- `int` → 기본
    
- `long` → 큰 정수
    
- `BigInteger` → 매우 큰 수
    
- 알고리즘 문제 → 대부분 `mod`
