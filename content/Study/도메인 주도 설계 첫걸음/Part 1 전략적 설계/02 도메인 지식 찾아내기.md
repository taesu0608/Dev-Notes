# 커뮤니케이션
- 효과적인 소프트웨어 = 도메인 전문가가 문제를 생각하는 방식
- 모델 변환
	- 도메인 지식 > 멘탈 모델 > 솔루션 모델 > 코드
- 모든 프로젝트 참가자가 동일한 문제 방식으로 접근해야 함

# 1. 유비쿼터스 언어
- 모든 프로젝트 참가자들의 공통된 이해를 위한 언어
## 일관성
- 유비쿼터스 언어의 특징으로 비즈니스 도메인의 로직을 명료하게 표현

# 2. 비즈니스 도메인 모델
## 모델 
- 사물이나 현상에서 의도한 관점만 강조하고 다른 측면은 무시하여 간략히 표현한 것
- Ex) 지도: 등고선 지도, 시간대 지도, 지형 지도
## 비즈니스 도메인 모델링
- 유비쿼터스 언어을 발전 > 비즈니스 도메인 모델 구축
## 도전과제
- 도메인의 중요한 지식은 도메인 전문가의 정신에만 존재함
	- 따라서 질문을 통해서 알아가야함
- 문서화나 도구를 통하여 유비쿼터스 언어 형성에 도움이 되지만
	- 결국 직접 사용을 하여야 함
