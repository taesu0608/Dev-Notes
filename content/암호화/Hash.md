# 1. Hash
**정의**: 해시(Hash)는 입력 데이터를 고정된 길이의 데이터로 변환된 값

## 1.1. Hash 구조도

![[dev_obsidian.drawio.svg]]

|       용어        | 정의                                                                    |
| :-------------: | --------------------------------------------------------------------- |
|      Hash       | (광의적) 입력 데이터를 고정된 크기의 값으로 매핑한 결과값.                                    |
|  Hash Function  | 임의의 크기의 입력을 받아, 고정된 크기의 해시값으로 변환하는 함수. 성능과 충돌 최소화가 핵심.                |
|    Hash Code    | (협의적) 특정 객체에서 생성된 고유한 해시값. 자바 등에서 객체 비교나 저장 시 사용됨.                    |
|   Hash Table    | `Key → Value` 구조로 데이터를 저장하며,<br>키의 해시값을 인덱스로 변환하여 데이터를 저장하는 자료구조.     |
| Hash Addressing | 해시 함수를 통해 데이터를 저장할 **주소(슬롯)** 를 계산하는 방식입니다.                           |
|      Slot       | 해시 테이블 내에서 데이터를 저장할 수 있는 단일 위치. 배열의 인덱스처럼 동작.                         |
|     Bucket      | 충돌된 여러 개의 값을 저장하는 하나의 **슬롯 공간** 또는 **연결 리스트** 구조. <br>해시 충돌 처리 시 사용됨. |
|     Hashing     | 데이터를 해시 함수에 넣어 해시값을 생성하는 과정. 해시 테이블의 인덱스를 정하는 단계.                     |
