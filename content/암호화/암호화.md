
# 1. 대칭/비대칭키 암호화

|         | [[대칭키 암호화]]          | [[비대칭키 암호화]]                              |
| ------- | -------------------- | ----------------------------------------- |
| 양방향 암호화 | 같은 키로 암호화 및 복호화      | 공개키로 암호화, 개인키로 복호화                        |
|         | AES, DES, RC4        | RSA, ECC, ElGamal                         |
| 단방향 암호화 | 대칭 키는 복호화가 전제이므로 불가능 | 개인키로 서명, 공개키로 서명 검증 가능 (예: RSA Signature) |
