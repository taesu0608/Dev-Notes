# 1. 정의
특정 입력값이나 컴퓨터 환경에 따라 **무작위로 선택한 것처럼 보이는 수(난수)**를 생성

의사난수(擬似亂數) = 擬(본뜰 의) + 似(비슷할 사)
- 실제 난수처럼 보이지만, **알고리즘에 의해 결정되는 가짜 난수**


# 2. 특징
- 항상 같은 환경, 같은 입력값이면 동일한 값 추출
- 의사난수는 이미 계산된 결과들을 표로 보관함
- 의사난수 또한 입력값에 의해 결정되므로 같은 방법으로 난수를 가져올시 처음을 제외하고는 난수라 할 수 없음

- 따라서 매개변수(seed 라고 함)를 달리 전달하여 매번 다른 의사난수를 생성함
	- 일반적으로 현재시간(Time)을 Seed로 사용

# 3. 알고리즘
- [[선형합동법]](Linear Congruential Generator, LCG)
	- 의사난수를 생성하는 대표적인 알고리즘
