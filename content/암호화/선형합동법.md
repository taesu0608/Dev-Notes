# 1. 선형합동법 (Linear Congruential Method)

선형합동법은 가장 널리 사용되는 의사난수 생성기(Pseudorandom Number Generator, PRNG) 중 하나로, 간단한 수식을 통해 의사난수 시퀀스를 생성하는 방식이다.

## 1.1. 정의

### 계산 공식
```lua
`Xₙ₊₁ = (A × Xₙ + C) mod M`
```

| 기호  | 설명                   |
| --- | -------------------- |
| Xₙ  | 현재 난수 또는 seed 값      |
| A   | 곱셈 계수 (Multiplier)   |
| C   | 덧셈 상수 (Increment)    |
| M   | 모듈로 (Modulus, 주기 결정) |

## 1.2. 동작 방식

1. 초기값(seed)을 정함
2. 수식에 따라 다음 수를 계산
3. 이 과정을 반복하여 난수열 생성
4. 생성된 수열은 무작위처럼 보이나, seed와 파라미터가 동일하면 항상 동일한 결과
---
# 2. 특징

- 계산이 간단하고 빠르며, 메모리 사용이 적음
- 구현이 매우 쉬워 고전적인 난수 생성기에서 널리 사용됨
- 하지만 `mod M` 연산 특성상 **변수의 최대 표현 범위 이상 주기**를 생성할 수 없음

---
## 2.1. 한계 및 보안 취약점

- 공식이 너무 단순해서 **예측이 가능**
- 일정 범위 내에서 난수열이 **반복되는 주기성** 존재
- 따라서 **암호학적 목적에는 부적합**    

---
## 2.2. 사용 사례

| 언어   | 함수 / 클래스           | 설명                 |
| ---- | ------------------ | ------------------ |
| C    | `rand()`           | 선형합동법 기반의 난수 생성 함수 |
| Java | `java.util.Random` | 내부적으로 선형합동법 변형 사용  |

이들 모두 내부적으로 **선형합동법 기반의 PRNG**를 사용함 (파라미터는 구현체마다 다름)

---
## 2.3. 요약

| 항목      | 내용                     |
| ------- | ---------------------- |
| 장점      | 연산이 단순하고 빠름, 구현 용이     |
| 단점      | 예측 가능성, 주기 제한, 암호에 부적합 |
| 적합한 용도  | 시뮬레이션, 일반적 무작위 시나리오 등  |
| 부적합한 용도 | 보안이 요구되는 환경 (토큰, 암호 등) |
