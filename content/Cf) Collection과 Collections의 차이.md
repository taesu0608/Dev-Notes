Java 공식 명칭
    - Oracle 공식 문서에서 전체 프레임워크를 **Java Collections Framework**라고 부름
    - `Collection`은 그 안의 **최상위 인터페이스**의 이름이고, `Collections`는 그보다 큰 개념(프레임워크 전체)을 의미합니다.

Collection vs Collections
    - `Collection` (단수) : `List`, `Set`, `Queue`의 **상위 인터페이스**.
    - `Collections` (복수)
	    1. 자바의 컬렉션 전체 생태계를 지칭
	    2. 유틸리티 클래스(`java.util.Collections`)
